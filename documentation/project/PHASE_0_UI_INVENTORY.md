# Phase 0 – Dashboard UI inventory (22 Nov 2026)

Generated by scanning every non-test `.ts`/`.tsx` file of the four role apps. The counts are of elements in the source (for example, `Buttons` = `<Button>`/`<button>`/`<IconButton>`, `Modals` = Modal/Dialog/Drawer/Sheet/ConfirmDialog, `Charts` = recharts charts). Shared building blocks live in `frontend/packages/shared-ui` and are counted where they are used. A file is listed when it renders interactive elements or reads data.

**Result of the scan for non-functional UI:** no empty `onClick` handlers, no `href="#"`, no `TODO`/`FIXME`, no mock or random data, and no "coming soon" toasts in any dashboard file. Every listed page reads or writes Supabase through the tables and RPCs shown. Pages without their own data calls (for example the Waiter dashboard and menu) use shared queries from `@sombill/api-client`.
